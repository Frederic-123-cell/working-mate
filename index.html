常见问题

断网还能用吗？

能。本地 Ollama 模型完全离线运行，对话、文件操作、工作流编排都不依赖网络。

我的数据会上传吗？

不会。对话记录、知识库、记忆全部存在你本机。

免费版有什么限制？

免费版可用全部本地能力与基础工具，界面含广告位；云端旗舰模型、AI 视频/音乐生成属于付费档。

支持哪些系统？

Windows 与 macOS。移动端（Android / iOS / 鸿蒙）在规划中。

模型会因为地区用不了吗？

部分海外厂商的闭源模型按账单地区限制。客户端启动时会自动体检，受限模型直接标注「🚫 地区受限」并在自动选模时跳过；同时内置 14 个国内直连平台（硅基流动、阿里云百炼、DeepSeek 官方等），不锁地区、一个 Key 打多家。

能填自己的 API Key 吗？

可以，而且推荐。任何 OpenAI 协议兼容的平台都行：硅基流动、阿里云百炼、DeepSeek 官方、火山方舟、智谱、Kimi、MiniMax、魔搭、OpenRouter……选中平台自动带出地址，粘 Key 即用；填两家还能自动互备。
